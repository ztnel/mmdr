# Mermaid review skill

Activates mmdr's environment-neutral diagram review capability. Requires its
five MCP tools; no Python scripts or other skills are loaded by this skill.

Install the plugin with Python 3.11+ and `uv` available to the MCP host.
See the [repository README](../../README.md) for workspace configuration and
CLI use. The application package, not the skill, owns process management,
source parsing, storage, and browser rendering.
